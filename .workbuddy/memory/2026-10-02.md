- 踩草涟漪修复：用户报"站着不动草像水波荡漾"。根因 = veg_wind.gdshader 涟漪项带 TIME 常驻动画。修复 = 新增每源"移动能量"（C++ 按帧速度算、平滑后经 trample_energy[8] uniform 传入）：凹陷常驻（站着草保持压倒），涟漪/外推只在能量>0（跑动）时出现。验证全绿。新坑记录：替换整块代码时多带了一层闭合括号（编译前 grep 复查抓到）。
- 起跳压草修复：用户报"主角跳起来的时候小草还是被压扁了"。根因 = ① veg_wind.gdshader 仅按水平 XZ 距离 d = length(dxz) 判断踩草范围，未计算 Y 轴垂直距离，浮空或在桥上/高空时仍会压扁正下方草；② C++ 计算每帧速度时用了 3D 距离，原地起跳瞬间垂直速度 (8.2m/s) 误判为狂奔移动，导致起跳空中触发最大水波涟漪；③ 缺少空中腾空状态门控。修复 = ① C++ 仅计算水平 XZ 速度；② C++ 检查 CharacterBody3D::is_on_floor()，空中 target 设 0，新增平滑着地权重 trample_weight（空中 0，地面 1，起跳时平滑回弹、落地时踩下）；③ veg_wind.gdshader 引入 trample_weight 门控 + 垂直高度衰减（根据脚底世界高度与草叶顶点世界高度差值衰减，脚底离草叶 >0.05m 开始衰减、>0.22m 完全脱离不压草，崖底仰望崖顶草同样不被踩）。验证全绿（scons 增量编译 0 error + 无头跑 120 帧 0 error/warn）。
- 连跳落地小草不倒塌修复：用户报"主角练跳（连跳）的时候，落地的瞬间小草也不会倒塌"。根因 = 连续跳跃时角色接触地面仅 1~2 个物理帧（~0.016s），此前平滑插值在 1 帧内最高只能爬到 0.25 且下一帧起跳 Y 坐标瞬间拔高，着色器垂直衰减短路导致小草还没来得及倒塌就恢复挺直；且真实世界中小草被踩踏有弹性恢复滞后（Hysteresis），人跃走后接地点小草需要约 0.3~0.5s 回弹。修复 = ① Player 增加 land_timer (0.4s) 与 last_land_pos，在落地边沿（on_floor && !was_on_floor）瞬间捕获接地点坐标与拉满倒伏权重；② TerrainBuilder 在角色腾空但处于 land_timer 窗口期时，将踩草源锁定在接地点地面坐标 last_land_pos，按 0.4s 曲线平滑弹回，空中身体不向下方误压草；③ 站在地面时权重持续拉满并跟随移动。验证全绿（scons 增量编译 0 error + 120 帧无头 0 error）。
- 脚步声与雨雪音效全重制：用户反馈"泥土路与球场声音一样且沙沙刺耳；下雨缺踩水声；下雪像开枪声；雨雪环境音一模一样且像铁棚敲击"。根因 = ① _step_kind() 未区分泥土路与球场草坪，全归草地且常驻触发 snd_rustle 野草沙沙；② make_step(false) 为瞬间白噪声爆音（-6dB），听感如开枪；③ make_wet 为泥浆拔脚吧唧声；④ Ambience 中 rain_gain 由 wet_s (rain+snow) 驱动，导致雪天播放满额雨声；且 make_rain 为 6 点滤波+硬脉冲，极像金属铁棚砸水。修复 = ① terrain_builder 公开 in_pitch 与 dist_to_path，Player 新增泥土路（snd_dirt，干爽坚实带细砂）与球场（snd_pitch，软弹细密吸音），且非荒草地关闭 snd_rustle；② 重构雪地脚步 make_snow() 为真实双段挤压咯吱声（15ms 软起音、双峰压雪、微晶挤压摩擦，音量压至 -11.5dB，彻底消除枪声感）；③ 重构雨天脚步 make_puddle() 为清亮水花轻溅踩水声；④ Ambience 雨声改为纯降雨驱动（雪天完全静音雨声，雪天只留宁静雪风），make_rain 改为双极粉化温润雨幕（1100Hz 截止 + 水面林梢微粒雨滴，彻底告别铁棚金属感）。验证全绿（scons 0 error + 120 帧 0 error）。
- 5大问题深度修复（走路声/蘑菇夜光/人畜穿模/萤火虫静止/动物发呆太久）：
  1. 走路声音问题：定位到 `_step_kind()` 中 `get_node_or_null(NodePath("TerrainBuilder"))` 因场景节点实际命名为 `"Terrain"` 导致始终返回 `nullptr`，球场与小径判定全部短路回退为草地，且 `rustle_voice` 在非深草区以不同相位循环播放杂草沙沙声。修复：修正节点查找（优先 "Terrain"），限制穿草声仅在深草区生效；重构 `make_grass()`（草土软接触）、`make_dirt()`（紧实微砂）、`make_pitch()`（吸音软弹）、`make_snow()`（双峰温润压雪咯吱声，消除 340Hz 调制刺耳高频）、`make_puddle()`（260->120Hz 滑频水花轻溅，替换原 210Hz 纯正弦波怪声）。
  2. 蘑菇夜光过曝问题：定位到 `terrain_builder.cpp` 中夜光能量倍率高达 1.7 与 1.1，经环境 Bloom 泛光后炸成白茫茫一大片光斑，完全掩盖蘑菇外形与斑点。修复：发光能量倍率降至 0.25 与 0.18，自发光改为柔和温润的朱红与月光淡白，夜幕下清晰分辨红伞、白点与菌柄。
  3. 人和动物穿模问题：定位到 `FarmAnimal` 与 `Rabbit` 为纯 `Node3D`，未挂载物理碰撞体。修复：为所有农场动物（牛/羊/狗/猫）及兔子挂载 `AnimatableBody3D` + `CylinderShape3D` 碰撞体并放置于 Layer 2（动态实体层）；Player 碰撞掩码开启 Layer 1 + Layer 2；动物 `ground_y` 射线检测显式限定 Layer 1，杜绝误触自身与其它动物；动物移动时增加对主角的距离避让检测。
  4. 萤火虫夜间静止不动问题：定位到 `world.tscn` 中 `Fireflies` 初速度极小（0.08~0.3）且阻尼高达 0.2~0.5，初速度在 1 秒内被完全阻尼为 0，且缺少轨道与切向加速度。修复：去除强阻尼（0~0.02），增加柔和微风浮力（gravity y=0.05）、切向与旋转加速度（tangential_accel ±0.45, orbit_velocity ±0.06），萤火虫在夜空缓慢三维盘旋漫游。
  5. 动物发呆时间过长/移动频率低/不自然：定位到状态机发呆时间长达 2~5s，吃草 2~4s，且待机时模型绝对静止如标本。修复：大幅缩短待机时间（猫狗 0.6~1.6s，牛羊 0.9~2.2s），吃草后直接启程漫游（游走几率升至 70%~80%），提升漫游航速；增加持续微动作——身体呼吸起伏、狗兴奋摇尾、猫尾卷翘摆动、牛羊周期甩尾、发呆时四处张望摆头、吃草时咀嚼起伏；兔子增加待机动鼻子与靠近受惊起跳。
  - 验证：scons 增量编译通过，无头运行 120 帧通过（0 error）。

  1. 灌木丛减速效果（"通过灌木丛要有减速效果"）：TerrainBuilder 收集所有灌木与浆果丛的中心坐标、半径与高度至 bush_obstacles，提供 is_in_bush(x, z, y) 空间碰撞判定；Player::_physics_step() 逐物理帧检测主角是否身处灌木丛，身处灌木丛时水平移动速度降低至 52%（明显的枝叶阻滞感），同时同步触发穿梭灌木的沙沙声（snd_rustle_deep），手感与听觉反馈自然逼真。
