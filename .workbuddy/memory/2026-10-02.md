    - 参数：amount 34、spread 62°、初速 2.2~4.8、重力 -9.5、damping 1.0~2.4、scale 0.05~0.15、`explosiveness_ratio=1.0`（一次性炸开）、`randomness_ratio=0.06`。
    - **相位同步**：`lifetime = 2π / shore_wave_speed`（= 2.244s，即拍岸浪周期），并用 `set_pre_process_time(period - delay)` 把发射时刻推到浪峰；`delay = fmod((π/2 + depth·freq)/speed, period)`，与 `water.gdshader` 里 `crest1` 的 `lap1` 逐字相同。常量 `REEF_WAVE_SPEED=2.8 / REEF_WAVE_FREQ=7.5` **必须与 water.gdshader 的 shore_wave_speed / shore_wave_freq 默认值一致，改一处要改两处**。
    - 结冰联动：`SkyCycle` 懒查找 `Terrain/ShoreSpray`，按 `amount_ratio = 1 - snow*1.6` 平滑淡出（缓存已写值，差 <0.01 不刷 32 个节点）。
  - 验证：`tests/qa_surf_phase.gd` 低机位连拍 12 张跨一个浪周期，`surf_08` 能看到浪打石头炸起一串白色水珠。

### 2. 水面真实感（CS2 向）
- **关键发现：写 `ALPHA` 会把材质扔进透明通道，而 Godot 的 SSR 只作用于不透明物体**（官方文档明确：「如果读取或写入 ALPHA，材质将进入透明管线」「透明材质不会出现在屏幕空间反射/折射中」）。水面着色器末尾原本有 `ALPHA = 1.0;`（注释写"手动合成折射，实际不透明"）—— 这一行就是水面映不出东西的根因，**已删除**。
- `world.tscn` 的 Environment：`ssr_max_steps=128`、`ssr_fade_in=0.05`、`ssr_fade_out=4.0`、`ssr_depth_tolerance=0.3`（原来只有 `ssr_enabled=true`，其余全默认）。
- `water.gdshader`：反射改成"引擎环境反射/SSR 为主 + 手搓天空色兜底"，`mix(base, sky_col, fres * 0.40)`（原 0.7，兜底层压薄以免盖掉引擎那层真反射）；`ROUGHNESS` 底值 0.02→0.015、`SPECULAR` 0.6→0.9。
- **雨点涟漪太假**：原来 `pw*2.2 / pw*4.7`、幅度 0.5、环宽 0.055 → 一圈圈又大又硬像气泡膜。改为 `pw*3.4 / pw*7.1`、幅度 0.26、环宽 0.040（细密小坑）。
- 验证：晴天（脚本里 `call("set_weather",0)` + rain/cloud 归零）水面变成亮蓝镜面、平滑浪带；雨天仍是深蓝 + 细涟漪。
- **注意**：`SkyCycle` 的 `weather / cloud / rain / snow` 只绑了**方法**没绑**属性**，GDScript 必须用 `sky.call("set_weather", 0)`，`sky.set("weather", 0)` 静默无效（HUD 还显示小雨就是这个原因）。
