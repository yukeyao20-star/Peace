# v0.2.0 实机验收清单

工程侧的无头自测已全绿（含菜畦 v3 三种作物、鱼获图鉴五鱼种与每日任务扩类回归）；这份清单是给**真人实机**用的：
拿到 `dist/` 四个包后，大约 20–30 分钟把 v0.2 全部新特性过一遍。玩法细节见 `PLAYING.md`，出包流程见 `RELEASING.md`。

## 一、验收对象（dist/ 四包，2026-10-24 19:21 版，含菜畦 v3 + 鱼获图鉴五鱼种 + 性能画面优化 + 每日任务扩类 + 热更旧包防护 + 暂停菜单/地图木质主题 + 地图图例与菜园木牌 + 小溪网格修复）

| 产物 | 平台 | 字节数（对包验证用） |
|---|---|---|
| `peace-macos-0.2.0.zip` | macOS universal | 184,576,675 |
| `peace-windows-x64.zip` | Windows x64 | 160,805,790 |
| `peace-linux-x64.zip` | Linux x64 | 151,684,857 |
| `peace-linux-amd64.deb` | Linux .deb | 133,552,944 |

包内入口：macOS 解压出 `Peace.app`（双击）；Windows 解压出 `peace-windows.exe` 与
`game3d.windows.template_release.x86_64.dll`（**两个文件必须放同一目录**）；Linux zip 解压出
`peace-linux.x86_64` 与 `.so`（同目录、`chmod +x`）；deb 直接 `sudo dpkg -i` 后从应用菜单或
`peace` 命令启动。

三个平台都**未签名**：macOS 首次打开需右键 → 打开，或 `xattr -cr Peace.app`；
Windows 会弹 SmartScreen（更多信息 → 仍要运行）。

> 窗口标题/进程名显示 "Peace" 而非「Peace」属已知偏离（项目内部名，勿改）。

> 本版起内置**热更旧包防护**：若 `user://` 残留 v0.1.x 时代旧补丁（`patch.pck`），启动时会自动跳过加载并改名隔离为 `patch.pck.staleN`（可回溯、不删除），不会再出现旧补丁资源覆盖新版画面的问题（v0.2.0 本体会提示"已是最新"）。

## 二、验收项

### A. 首次启动与新手引导（建议删掉旧存档开新档验）

- [ ] 首启无报错进入世界，顶部 HUD 时钟正常（时段/天气/月相/第 1 天）。
- [ ] 第 1 天待办 = **采浆果 0/6**，左上常驻面板；底部操作提示**不自动消失**，直到你完成第一次交互才淡出。
- [ ] 最近一丛有果的浆果丛上方悬着金色 **「▼ 采浆果」浮标**（穿墙可见、上下浮动）；走近 5 米内浮标收起，由物体旁的黄色提示接管。
- [ ] 换个任务类型再瞄一眼浮标：打井水/开木箱指各自位置、足球跟着球走、**钓鱼指湖心**（走近湖边 12 米内由「按 F 抛竿」提示接管）。
- [ ] 屋前可见小溪：溪流从木桥下穿过、汇入大湖处水面自然衔接（本版修复项：溪流网格曾整条缺失导致"小溪消失"）。

### B. 暂停菜单与设置

- [ ] `Esc` 呼出暂停菜单（木质主题：悬浮木牌面板 + 浅松木刻字主按钮 + 木面凹槽滑条，标题「· 湖 畔 小 憩 ·」），世界完全停住（时间不走、动物不动）；再按 `Esc` 返回。
- [ ] 音量滑条拖到 50% → 退出重进 → 音量仍是 50%（`user://settings.cfg` 持久化）。
- [ ] 「画质：高/低」切换即时生效：低档关 SSR/SSAO/Glow + 0.7 倍渲染缩放，重进后仍记住选择。
- [ ] 全屏切换即时生效。
- [ ] `M` 打开地图：图例含 **🌱 菜园 / 🐄 牧场 / 🌉 石桥 / 🎣 湖畔** 等七处标注，菜园画嫩绿格纹块、东侧有淡黄牧区色块；世界里的菜畦在宅东侧开阔地，菜园西侧入口立有「菜园」木牌（Label3D 木刻字，牌面朝西/朝宅院）。
- [ ] 「保存并退出」能正常退出且存档。

### C. 五类玩法 + 菜畦

- [ ] **采浆果**：园里 3 丛 + 林缘野生丛都可采（按 `E`），采空约 45 秒重新结果。
- [ ] **菜畦**：空畦旁按 `R` 换种（浆果 90s/+2 · 萝卜 60s/+3 · 南瓜 150s/+5，提示与缩放预览跟随切换）；播种 → 长成 → 收获按作物发对应产量；**打水后 20 秒内**对生长中菜畦按 `E` 浇灌（生长 +30%，一茬限一次，浇过土垄变深色）。
- [ ] **钓鱼**：湖边按 `F` 抛竿蓄力，控力条绿区把鱼拉上来（鱼有随机体长，破纪录带 🏅）；按 `B` 呼出右侧「鱼获图鉴」面板，再按 `B` 收起。
- [ ] **鱼种**：共五种——白天湖里主要是**青鳞鱼**（偶尔**红尾鲤**），夜里换成**月影鲈**（偶尔**夜鳗**），昼夜都有小概率钓上罕见的**金鳞鱼**（修长难拉、暗金色鱼影）；咬钩前看水下鱼影颜色可分辨鱼种，图鉴里未钓到过的种显示「？？(昼行/夜行)」，钓到后逐种累计条数与最长纪录。
- [ ] **足球**：东侧球场走近球自动踢出，射进任一球门计「足球进球」。
- [ ] **打井水**：井边按 `E`，能听到辘轳吱呀 + 水花音效（约 1 秒）。
- [ ] **木箱彩蛋**：**首次**开箱弹中央公告「从木箱里翻出一条野餐毯！」，箱旁屋内摆出毯子 + 藤篮，有「叮咚」提示音；之后再开关箱子不重复公告。
- [ ] **喂动物**：走近小猫/小狗/奶牛/绵羊按 `E` 喂食（8 秒进食冷却防连刷），动物开心跳一下、奶牛哞一声；当天清单含「喂动物」时计 1 次。

### D. 存档恢复（v5 重点）

- [ ] 推开木屋门、推开一两扇窗 → 走远等一次自动存（30 秒）或手动保存退出 → 重进后**门/窗保持打开姿态**（门连推/拉的方向也对）。
- [ ] 当日待办进度、木箱彩蛋（毯子在位、不重复公告）、菜畦作物/生长/浇灌状态重进后都恢复。
- [ ] 第 2 天起清单按天抽 3 项（采浆果恒在，另从钓鱼/进球/打水/开箱/**照看菜畦/喂动物**抽二），同一天重进清单不变；床上按 `E` 睡觉或自然午夜跨天弹新清单横幅。收获一茬成熟作物计「照看菜畦」、喂食计「喂动物」，方向浮标对这两类分别就近指成熟菜畦/最近动物。

### E. 天气与冰面（需要等一场雪）

- [ ] 下雪时湖面从岸边向湖心逐渐冻结、冰蓝裂纹。
- [ ] 雪量**近满**（HUD 顶栏天气转「雪」后多等一会儿，约再 1–2 分钟）后可以直接走上大湖冰面：移速明显变快（+65%）、急停漂移、起跳带转体——滑冰手感。
- [ ] 冰面没冻透的中段（雪量 0.20–0.85 区间）蹚水走**不会**误触滑冰；溪流和瀑布深潭冻得早（雪量 0.20 起），可提前踏冰抄近道。
- [ ] 雪停后冰面消融会落回水里蹚水，从岸边重新上岸即可（预期行为，不是 bug）。

### F. 声音与性能

- [ ] 环境音分层可闻：风声常驻、雨天雨声、夜间虫鸣、近湖有水拍岸、靠近木屋有壁炉柴火；进屋后室外风雨雪声明显衰减。
- [ ] 性能参考 `PERF.md`：默认画质 Apple M4 约 10–18fps（Retina 全分辨率），瓶颈是场景几何量，属 v0.2 已知事实；低档画质约 −44% 帧成本。实机顺手记一下默认/低档的大致帧率即可，写回 `PERF.md` 第三节更好。

## 三、遇到问题怎么记

- 项目日志在 `~/Library/Application Support/Godot/app_userdata/Peace/logs/`（godot.log）。
- 启动加 `--print-fps` 可前台看帧率；`tools/perf_probe.gd` 是离屏帧成本探针。
- 退出日志末尾出现 `N resources still in use at exit` / ObjectDB 计数**属已知退出时序噪声**，各次运行数值不定，无害，不算验收失败。
- 其余「已知限制」以 `PLAYING.md` 末节为准（固定种子、单存档位、天气不可指定、温度纯氛围）。
