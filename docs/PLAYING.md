# 怎么玩 — Peace玩家指南

欢迎来到Peace！这是一份面向玩家的上手指南：怎么操作、怎么玩、画面里每个东西是什么。

---

## 目标与进度

当前版本的玩法目标是**每日待办清单**——每天一张小清单，做完睡觉进入新的一天：

- 屏幕左上角常驻显示当日待办，例如：

  > **今日待办 · 第 2 天**
  > `·` 采浆果 0/4
  > `·` 足球进球 0/1
  > `·` 开木箱 0/1

- **第 1 天**是新手引导：采浆果 ×6（找到长红色小果实的灌木，靠近按 `E` 采摘，每颗进度 +1）。浆果丛除了院子里的 3 丛，**林缘树下还散布着 20 丛野生浆果丛**，同样可采。
- **第 2 天起**每天从七类里确定性抽 3 项：**采浆果（恒在）/ 钓鱼 / 足球进球 / 打井水 / 开木箱 / 照看菜畦 / 喂动物**——同一天重进游戏清单不变。
  - 照看菜畦：收获一茬成熟作物即计 1 次（种法见"菜畦"条目）。
  - 喂动物：走近小猫/小狗/奶牛/绵羊按 `E` 喂食（动物会开心跳一下，奶牛哞一声；8 秒进食冷却）。
  - 钓鱼：走到湖边按 `F` 抛竿，控力条保持在绿区把鱼拉上来。**五种鱼**：白天有**青鳞鱼/红尾鲤**，夜里换**月影鲈/夜鳗**出没，还有 6% 概率的全时段稀有**金鳞鱼**（鱼影泛金光）；鱼影颜色就是鱼种的第一辨识度。每条鱼有随机体长，钓上该鱼种最长的一条会标注 🏅**新纪录**；按 `B` 打开鱼获图鉴看五种鱼的累计与最长纪录（没钓到过的鱼只显示"？?（昼行/夜行）"）。
  - 足球：地图东侧球场，走近球自动踢出，把球送进任一球门。
  - 井水/木箱：靠近按 `E`。
- **方向指示**：清单里第一个未完成项的目标上方，悬着一块金色「▼ 任务名」浮标——采浆果指最近的果满丛（采空自动换丛）、钓鱼指湖心（走到湖边由「按 F 抛竿」提示接管）、足球跟着球走、井/木箱指各自位置；走近目标约 5 米内自动收起，任务切换后浮标跟着挪。
- 当日全部完成时，屏幕中央弹出金色大字——

  > **第 N 天 · 今日待办全部完成！**
  > 回床上睡一觉，迎接新的一天

- **跨天**（自然到午夜，或回木屋床上按 `E` 睡觉）自动发布新一天的清单，中央横幅提示「第 N 天 · 新的待办已发布」。
- 浆果丛被采空后约 **45 秒**重新结果，可以反复采集。
- 进度自动存档（每 30 秒 + 退出时），重进游戏从当天清单继续。门窗开合、木箱彩蛋、菜畦状态也都随存档恢复。

> 达成当日清单后没有强制结局，小岛就是你的沙盒：继续探索昼夜、天气与每个角落。

## 操作

| 按键 | 动作 |
|------|------|
| `W` `A` `S` `D` / `↑` `↓` | 移动（W 朝画面深处，随视角转向） |
| `←` `→` | 旋转视角（键盘转向；与鼠标视角可叠加） |
| `空格` | 跳跃（空中可二段跳） |
| `E` | 互动 |
| `R` | 滚动冲刺（空菜畦旁＝换种） |
| `G` | 放烟花（夜晚） |
| `M` | 大地图：动态全图漫游 + 瞄准星瞬移 |
| `B` | 鱼获图鉴：小鱼/大鱼累计与最长纪录（随钓鱼自动入账，持久保存） |
| `Esc` | 暂停菜单：继续 / 音量 / 画质 / 全屏切换 / 保存并退出；大地图打开时只收起地图 |
| 鼠标 | 点击画面捕获视角，滚轮缩放距离 |

- 靠近可交互物（3.2 米内）时，物体会上方浮现**黄色提示文字**，此时按 `E` 触发互动。
- 推门/推窗时，角色会播放一个前倾的"推"的小动作。
- 走路有脚步声，且会随脚下变化：草地、雪地、雨天湿泥、石桥石板四种音色；雪积厚了踩上去是嘎吱声。

### 暂停菜单

按 `Esc` 呼出：整个世界（时间、天气、动物、HUD 计时）会完全停下，再做以下事——

- **继续游戏**：按钮或再按 `Esc` 返回；
- **音量**：拖动滑条调节整体音量，设置会记住（下次启动自动恢复）。底层走 Master/SFX 双总线混音：脚步、交互、结算等一次性音效在 SFX 总线，风/雨/虫鸣/湖水/壁炉等环境循环层在 Master，滑条总控全部声音；
- **画质：高/低**：低档（流畅）一键关闭 SSR 水面反射、SSAO 环境光遮蔽、Glow 辉光三大后处理特效，并把渲染分辨率降到 0.7 倍再放大回填（实测中低配机器收益最大的一档），画面整体构图不变、水面倒影退化为着色器内置天空兜底，老机器卡顿时用；设置会记住（下次启动自动恢复）；
- **全屏：开/关**：即时切换窗口化（最大化）与全屏；
- **保存并退出**：立即存档并关闭游戏。

## 可交互物一览

| 对象 | 怎么用 | 效果 |
|------|--------|------|
| **浆果丛** | 靠近按 `E` 采摘 | 采到一颗浆果（目标进度 +1），约 45 秒后重新结果；下雪时枝头也会盖雪 |
| **菜畦**（院内） | 靠近按 `E` 播种；空畦旁按 `R` 换种 | 三种作物随心种：**浆果**（90 秒 / +2）· **萝卜**（60 秒 / +3，快产）· **南瓜**（150 秒 / +5，慢熟高产）；成熟后按 `E` 收获，产量直接计入当日待办，可循环种植 |
| **菜畦 · 浇灌** | 打水后 20 秒内对生长中菜畦按 `E` | **浇灌：生长 +30%**（提示会变成"按 E 浇灌"，一茬限一次，浇过土垄变深色）；菜畦状态随存档保存，下雪时菜畦自动盖雪 |
| **木屋门** | 靠近按 `E` 推门 | 开门/关门，可以走进木屋看室内 |
| **百叶窗** | 靠近按 `E` | 推开/关上百叶窗 |
| **木箱** | 靠近按 `E` 开箱 | 打开/关上木箱；首次打开翻出一条野餐毯（一次性彩蛋：毯子+藤篮摆在箱旁，存档保留，中央有公告） |
| **水井** | 靠近按 `E` 打水 | 在井边打一桶井水（辘轳吱呀 + 水花音效）；打水后 20 秒内可给生长中的菜畦浇灌（见上） |

提示文字会随状态变化（门开着提示"关门"，关着提示"开门"）。

## HUD 顶部时钟怎么读

屏幕顶部一行显示：

```
[月相图标] 08:37 · 白天 · 晴 · 满月 · 第 1 天 · 20°C
```

各字段含义：

| 字段 | 含义 |
|------|------|
| **月相图标** | 当晚月相的程序化绘制（明暗界线实时建模），夜晚抬头看月亮也是同一相 |
| **08:37** | 游戏内时刻；**一天 = 4 分钟现实时间**（240 秒） |
| **白天** | 时段（清晨 / 白天 / 傍晚 / 夜晚） |
| **晴** | 当前天气（晴 / 多云 / 小雨 / 大雨 / 雪） |
| **满月** | 当日月相名，共八相：新月 → 娥眉月 → 上弦月 → 盈凸月 → 满月 → 亏凸月 → 下弦月 → 残月 |
| **第 N 天** | 游戏天数；**第 1 天是满月，之后 8 天一个朔望循环** |
| **xx°C** | 当前气温 |

## 昼夜与天气对世界的影响

这个岛是"活"的，时间与天气会真实改变世界：

### 昼夜

- 太东升西落，夜晚切换为月光照明，晴天夜空可见 **220 颗星**与带陨石坑的月盘（含暗面微光"地照"）。
- **萤火虫**只在夜间 + 非雨雪天出现。
- **蘑菇**夜里发出幽幽夜光，伞盖上还有光尘飘浮（雨雪天减弱）。
- **兔子**天黑了回窝趴睡，天亮起身；**鸟**夜里不叫。

### 天气（晴 ⇄ 多云 ⇄ 小雨 ⇄ 大雨 ⇄ 雪）

天气随机流转、平滑过渡。下雨/下雪时：

- 天空压暗、雾变浓，雨/雪粒子跟随你移动。
- **湖面结冰**：下雪时湖水逐渐冻结——岸边浅水先冻，冰面向湖心推进，出现冰蓝色与脊线裂缝，冰面如镜。
- **冰面可行走（雪量近满时）**：雪量近满（约 0.85）后湖水冻透，可以直接走上冰面横穿大湖——脚下自动穿上滑冰鞋，移速 +65%，急停会丝滑漂移滑行，起跳带一整圈优雅自转；溪流与瀑布深潭冻得早（雪量 0.20 起），可以提前踏冰抄近道；雪停后冰面消融，冰面碰撞自动解除（站在冰上会落回水里蹚水，从岸边重新走上岸即可）。
- **积雪**：低处地面先积起雪，随雪量增大逐渐爬上山坡；树冠分三层先后挂雪毯，蘑菇伞顶最先覆雪；浆果丛、草地上也会盖雪。
- **生物躲雨雪**：鸟不鸣叫（也不低飞）、兔子回窝趴睡、蝴蝶落进草丛静栖；雨停雪停后它们陆续恢复活动。
- **脚步声变化**：雨大时踩湿泥"吧唧"，雪积厚了（雪量足够）踩雪地嘎吱。

## 已知限制

- 世界为**固定种子**程序化生成：每次进游戏地形、湖、桥、宅院布局完全相同（种子 1337）。
- 相机为第三人称跟随视角：点击画面捕获鼠标转向（`Esc` 释放），`←`/`→` 键盘转向兜底。
- 存档为单槽位本地存档（`user://savegame.cfg`），暂无多存档位。
- 天气流转为随机状态机，无法手动指定天气。
- 温度仅作氛围显示，尚未参与玩法。
- 每日清单覆盖七类玩法（采浆果/钓鱼/足球/打水/开箱/菜畦/喂动物）+ 家园菜畦；更多玩法留待 v0.3。
