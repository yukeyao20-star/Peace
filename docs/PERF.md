# 性能基线与低配兜底（P1#9）

> 2026-10-24 首次建档。目标：给"性能基线实测 + 低配画质开关"留一份可持续更新的事实底账。

## 一、已实测数据

### 逻辑帧基线（headless，可信）
- `--headless --quit-after 120` 冒烟：0 报错；QA 报告（v0.1 时期）300 帧 avg 7.46ms / p95 6.94ms / 首帧 150ms 预热尖峰。
- 现地图规模已远超 QA 时期（草 4200 → 100000 实例、瀑布/球场/深潭等新增），逻辑帧未见恶化（headless 长跑零尖峰）。

### 渲染帧率（本机 macOS，脚本化测量**不可信**）
- 用 `-s` SceneTree 脚本窗口测得 ~10fps（三机位 avg 9.9~11.5），**不代表真实性能**：
  macOS 对拿不到键盘焦点的脚本窗口强制节流（`window_move_to_foreground()` 也无效）。
- ⚠️ 结论：**渲染帧率必须在真实游玩（窗口有焦点）时测**，脚本化方案在 macOS 上不可用。

### 渲染负载基线（2026-10-24 窗口探针实测，可信）
- 方法：`-s` 探针把 Player 相机摆到目标机位，每帧采 `Performance` 监视器取均值。
  draw call / 三角数 / 物体数 / 显存是**每帧计数器，不受 macOS 后台节流影响**（节流只拉长帧间隔，不改变一帧画了多少）。
- 数据（3840×2160 窗口，Retina 2x）：

| 机位 | draw calls | 三角形/帧 | 物体/帧 | 显存 |
|---|---|---|---|---|
| 出生点宅基地全景（远景含树林） | ~2100–2640 | ~19.0M | ~2400–2890 | 1.13 GB |
| 湖面开阔视角（对大湖，地形遮挡多） | ~500 | ~18.7M | ~730 | 1.13 GB |

- 解读：draw call 随视角波动大（树丛/宅基地密集处 ~2600，开阔湖面 ~500），三角形数稳定 ~19M（草 10 万实例的 MultiMesh 恒在视锥内）；显存 ~1.13 GB 为地板值。
- **帧率/帧时间仍需实机**：以上是"一帧画多少"的事实底账，"每秒画几帧"只能在有焦点的真实游玩里测（清单见第三节）。

### 帧成本阶梯（2026-10-24 离屏回读探针实测，可信）
- 方法：新工具 `tools/perf_probe.gd`——`RenderingServer.force_draw(false)` 离屏渲染 + 视口回读强制 GPU 同步，
  单帧墙钟 = 真实 GPU 帧成本，**不经窗口呈现，免疫 macOS 节流**；空场景回读基线（~8.5ms@3840×1944）已从下表扣除（净值）。
  SkyCycle 锁正午+晴天（每机位采样前重申）；两次独立全量运行关键机位偏差 <1%。
- 数据（Apple M4 / Metal 4 / Forward+ / 渲染 3840×1944 Retina 2x）：

| 机位 | 高画质（特效开, 缩放1.0） | 低（特效关, 0.7） | 极低（特效关, 0.5） | 图元/帧 |
|---|---|---|---|---|
| 出生点宅基地 | 55.6ms（≈18fps） | — | — | 18.2M |
| 湖南岸向湖 | 65.6ms（≈15fps） | — | — | 18.7M |
| 石桥西岸（SSR 最重） | 58.6ms（≈17fps） | 37.6ms（−36%） | 32.8ms（−44%） | 18.7M |
| 足球场（10 万草，几何最重） | 101.3ms（≈10fps） | 81.5ms（−20%） | 73.9ms（−27%） | 21.4M |
| 瀑布深潭 | 60.1ms（≈17fps） | — | — | 18.7M |

- 解读：
  - **默认画质连 Apple M4 也只有 10~18fps，60fps 全线不达标**——瓶颈是每帧 18~21M 图元的几何量
    （10 万草 MultiMesh 恒在视锥，与上节"三角形数稳定 ~19M"互证），不是后处理；
  - 关 SSR/SSAO/Glow 仅省 7~19%（球场几乎看不到水面，仅 −20%）；**像素缩放 `scaling_3d_scale` 才是有效杠杆**
    （0.7 档桥机位再省 21ms），0.5 档收益已递减（进入几何/draw-bound 区）——画质开关若要增强，
    低档建议叠加 scaling≈0.6~0.7（是否纳入由后续会话/用户定夺）；
  - draw calls 跨档位非单调（球场 low 2347 > high 1489），机理未查，**不作稳定指标，以帧成本为准**；
  - 全部数字按 Retina 2x 渲染；外接 1x 显示器像素成本约降为 1/4，几何成本不变。
- 复跑：`HOME=$PWD/tmp/test_home /Applications/Godot.app/Contents/MacOS/Godot --path project -s "$PWD/tools/perf_probe.gd" --quit-after 5000`（约 3 分钟，`grep '^PERF'` 提取结果）。

## 三·五、2026-10-24 优化落地(会话A)
- **草毯分块剔除**:GrassTufts 10 万实例由 1 张全图 AABB MultiMesh 切成 36 块 80m 网格子 MultiMesh(commit_scatter_chunked,实例数/位置逐个守恒=100000 实测)——视锥剔除按块生效,典型机位草顶点提交量降至原先零头。
- **SSR 128→64 步 + fade_in 0.08**:反射实测无缺失无噪点(南岸看桥截图验证)。
- **壁炉 OmniLight 阴影关闭**(6.5m 小范围火光的立方体阴影图,视觉损益≈0)。
- **画面升级(有代价项)**:太阳软阴影 shadow_blur 1.0、MSAA 2x→4x、微色彩分级(对比 1.04/饱和 1.06)——出生点截图验证草毯完整/软影/低锯齿/色彩自然。
- 净效果预期:剔除+SSR+灯影的节省盖过软影+4xMSAA 的开销;真实帧率仍待实机(见第三节清单)。

## 四、低配画质开关（✅ 2026-10-24 已接入暂停菜单）
运行时降画质无需改场景文件，C++ 侧直接：
```cpp
// WorldEnvironment 节点 → environment 资源（运行时改即生效）
env->set_ssr_enabled(false);   // 最大头：水面反射退化为着色器内置天空兜底（权重已调至 0.32，不致死）
env->set_ssao_enabled(false);
env->set_glow_enabled(false);
```
- **接入点（已交付）**：暂停菜单「画质：高/低（流畅）」按钮（`pause_menu.cpp` on_quality_pressed）——
  低档关 SSR/SSAO/Glow 三特效 **+ 渲染缩放 `scaling_3d_scale` 0.7**（高档复位 1.0），即时生效；
  持久化 `user://settings.cfg` `[video] quality_low`，开机 `apply_quality()` 自动应用；
  环境节点/视口缺失（测试/异常场景）静默跳过功能无损。
- 验证：-s 自测 18 断言全绿（默认高档/来回切换三特效+缩放/文案/落盘/跨运行恢复/音量段共存）；
  窗口化截图对比确认低档 Glow 光斑泛光消失、画面整体协调；整图无头冒烟 0 SCRIPT ERROR。
- 不动 terrain_builder 撒点参数（改实例数会挪随机序列导致整图重排，硬坑）。
- 实测参考（见第一节「帧成本阶梯」）：仅关三特效在 M4 上省 7~19%；**缩放杠杆已纳入低档**
  （0.7 档实测桥机位 −36% 帧成本，与 tools/perf_probe.gd 的「低」档配置一致；0.5 档收益递减未采用）。
